# 🎵 ProjectMix - Web Music

Site institucional de uma escola de música e produção musical, com cursos para diferentes estilos, apresentação da equipe e formulários de contato e cadastro.

## ✨ Sobre o projeto

O **ProjectMix** reúne em um só lugar tudo o que o aluno precisa para conhecer a escola e começar a aprender: cursos, serviços, informações sobre a equipe e canais de contato. O layout é visual e moderno, com imagens, GIFs e vídeos que mostram o ambiente musical.

## 📄 Páginas

| Página | Descrição |
|---|---|
| **Início** (`index.html`) | Apresentação do projeto e destaques |
| **Sobre** (`sobre.html`) | Conheça a escola e a equipe |
| **Serviços** (`serviços.html`) | Serviços oferecidos |
| **Cursos** (`cursos.html`) | Visão geral dos cursos |
| **Curso de Eletrônica** (`cursoeletronica.html`) | Música eletrônica e produção |
| **Curso de MPB** (`cursompb.html`) | Música popular brasileira |
| **Curso de Rap** (`cursorap.html`) | Rap e criação de beats |
| **Curso de Rock** (`cursorock.html`) | Rock, guitarra e banda |
| **Cadastro** (`cadastro.html`) | Formulário de inscrição |
| **Contato** (`contato.html`) | Fale com a gente |

## 🛠️ Tecnologias

- HTML5
- CSS3

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/vitor7-dev/ProjectMix---Web-Music.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd ProjectMix---Web-Music
   ```
3. Abra o arquivo `index.html` no navegador.

> **Nota:** os vídeos da pasta `videos/` estão armazenados com [Git LFS](https://git-lfs.com). Para baixá-los, instale o Git LFS e rode `git lfs pull`.
